# Changelog

## 1.0.0

First reusable release of **Along the Way**:

- A 50-second, eight-scene ink animation and editable SVG character poses.
- Custom farewell wording, signature and optional local music.
- Four-person goodbye with continuous walking and doorway staging.
- Vector-print/PDFium export to avoid incomplete SVG screenshot frames.
- Motion, continuity and export-input regression tests.
- Licensed handwriting font, silent preview GIF and final-card example.

Verified with Node.js 25, Python 3.12, Chrome and FFmpeg on macOS. Other platforms need visual export review.
