# Optional music

The template runs silently without an audio file.

Add your own recording here, then set `musicFile` to a path relative to `public`, for example `audio/my-track.mp3`. Set `musicStartSeconds` and `musicVolume` in your props JSON. The soundtrack fades in, softens under the final message, and fades out.

Audio files are ignored by Git. No third-party song is bundled or downloaded automatically.
